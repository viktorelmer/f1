# Детерминированный ГСЧ и именованные потоки (M1)

Раздел 3.3 плана: один сид на партию, от него именованные подпотоки. Так добавление новой системы не сдвигает случайность в старых.

## Модель

- **Генератор** — xoshiro128** со 128-битным состоянием. Он работает только на 32-битной арифметике (`Math.imul`, сдвиги), поэтому быстрый в JS и одинаковый на любой платформе. План допускает seedrandom или собственный PCG32. PCG32 отклонён: ему нужно 64-битное умножение, в JS это `BigInt`, а он на порядок медленнее, что ощутимо для батч-прогонов на тысячи сезонов. seedrandom отклонён как зависимость ради 30 строк кода.
- **Поток** выводится из пары (сид партии, имя потока) хешем cyrb128. Хеш даёт четыре 32-битных слова начального состояния. Поток ничего не помнит между процессами: `rng(name)` всегда начинается с одного и того же состояния.
- **Сид** — строка. Игрок может ввести её или поделиться ею. Случайный сид для новой карьеры генерирует слой `app` через `crypto`, а `sim` получает его готовым.

```ts
type Rng = {
  next(): number;                  // [0, 1)
  int(min: number, max: number): number;    // оба конца включительно
  range(min: number, max: number): number;  // [min, max)
  chance(p: number): boolean;
  normal(mean: number, sd: number): number; // полярный метод Марсальи
  pick<T>(items: readonly T[]): T;
};
function streams(seed: string): (name: string) => Rng;
```

## Правила имён потоков

- Формат: `<система>:<область…>:<id сущности>`, например `world:hidden:driver:r-hart`, `race:2027:r05:incidents`, `market:2027:w12:offers`.
- Имя строится только из id и дат, никогда из индекса в массиве или порядка обхода. Если в пак добавить пилота, скрытые величины остальных не изменятся, и это покрыто тестом.
- Один поток обслуживает один ограниченный процесс: одну гонку, один тик рынка, одну генерацию. Следующий процесс получает своё имя. Поэтому состояние ГСЧ в сейв не пишется, его всегда можно вывести заново.

## Где случайность входит в M1

| Поток | Что порождает |
|---|---|
| `world:hidden:driver:<id>` | `potential`, `growthRate`, `injuryProneness` пилота |
| `world:hidden:team:<id>` | скрытые величины команды (корреляция аэротрубы) |
| `world:knowledge:<teamId>:driver:<driverId>` | шум первичной оценки потенциала (см. estimate.md) |

## Константы и тесты

Своих балансных констант у ГСЧ нет. Тесты:

- определённые сид и имя потока всегда дают один и тот же хеш первой тысячи значений;
- разные имена дают независимые последовательности;
- `int` и `range` не выходят за границы;
- выборочные среднее и дисперсия `normal` в допуске.

**Известное ограничение:** `normal` использует `Math.log` и `Math.sqrt`. Побайтовая одинаковость гарантируется в пределах одного JS-движка (V8: Node и Chrome). Сверка между движками — задача будущего мультиплеера.
