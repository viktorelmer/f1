# Changelog

Вехи из `f1-manager-plan.md`, раздел 7. Веха считается сделанной, только когда у каждого пункта DoD есть подтверждение.

## M1 · Домен и контент — 2026-09-10 — готово

Решения: [ADR 002](adr/002-m1-domain-and-content.md). Design-notes: [rng](systems/rng.md), [estimate](systems/estimate.md), [decide](systems/decide.md), [world](systems/world.md).

### Что сделано

- **ГСЧ** (`src/sim/rng/`): xoshiro128**, именованные потоки из пары (сид, имя).
- **Оценки** (`src/sim/knowledge/`): `Estimate<T>`, `measure()`, `observe()`, `refine()`. Разброс и смещение задаются независимо, смещение не хранится нигде.
- **Решения** (`src/sim/decide/`): контракт `decide()` → `Decision<T>`, общий `chooseByScore`. Делегирование: 11 областей, 3 режима, связка «область → роль», 3 пресета, доступность по наличию роли в штате.
- **Доменная модель** (`src/sim/types/world.ts`): все сущности из 4.2. Скрытые величины вынесены в `world.hidden`, оценки команд — в `world.knowledge`.
- **Формат пака** (`src/data/schema/pack.ts`): схемы Zod с перекрёстными проверками, `parsePack()` возвращает все проблемы сразу.
- **Пак по умолчанию** (`src/data/packs/default/`):
  - 22 трассы с профилями, погодой, заводскими сетапами и реальной геометрией из bacinger/f1-circuits (MIT; скрипт `npm run pack:geometry`);
  - 11 команд с историей, моторами, узлами шасси, зданиями, департаментами, финансами, спонсорами и характерами ИИ;
  - 22 боевых пилота и 40 резервистов (11 штатных резервистов и 29 свободных агентов);
  - 4 поставщика моторов, 197 сотрудников;
  - регламент и календарь 2027 года (22 этапа, 6 спринтов), условия режима B.
- **Характеристики болида** (`src/sim/car/`) вычисляются из узлов и мотора по весам баланса.
- **Генератор мира** (`src/sim/world/`): `createWorld(seed, pack, career)` для режимов A и B, `checkWorld()` — инварианты мира.
- **Баланс** в формате `{ value, why }` с проверкой при загрузке: `estimate`, `decide`, `car`, `career`.
- **Защита слоёв** ESLint распространена на `src/data/`.

### DoD

| Пункт | Подтверждение |
|---|---|
| `createWorld(seed, pack, careerMode)` возвращает валидный мир | `create-world.test.ts` → «returns a valid world» для режима A и режима B: `checkWorld` находит 0 нарушений |
| При разных сидах видимое стартовое состояние идентично, скрытые величины различаются | «leaves the visible world identical and varies hidden values — mode A / mode B»: мир без `seed`, `hidden` и `knowledge` совпадает побайтово, у большинства пилотов скрытые величины различаются. Плюс «adding a driver to the pack moves nobody else» и закреплённые хеши мира для каждого режима |
| Схемы отвергают битые данные | `pack.test.ts` → «parsePack rejects broken data», 15 случаев: нет поля, лишнее поле, значение вне диапазона, несуществующая дата, висячая ссылка, дубль id, общий id у пилота и сотрудника, три боевых пилота, пустой диапазон, нет роли, чужой пилот у инженера, DRS не совпадает с геометрией, неизвестная трасса и нарушенный порядок в календаре, занятый сотрудник в режиме B; плюс проверка, что сообщаются все проблемы. `balance.test.ts` — значение без комментария не загружается |
| Есть тесты на обе ветки режима | `create-world.test.ts`: наборы «career mode A (takeover)» (5 тестов) и «career mode B (founder)» (10 тестов, включая отказ на недопустимые настройки) |

Проверки: `npm run typecheck`, `npm run lint`, `npm run format:check` — без ошибок. `npm test` — 160 тестов в 13 файлах, все проходят. `npm run build` проходит. `parsePack` занимает около 35 мс, `createWorld` — около 2 мс.

## M0 · Каркас — 2026-09-10 — готово

Решения: [ADR 001](adr/001-m0-scaffold.md). Design-note: [app-shell](systems/app-shell.md).

### Что сделано

- Vite 8, React 19, TypeScript 6 (strict, `noUncheckedIndexedAccess`), ESLint 10 (линтинг с типами), Prettier, Vitest 5 с проектами `sim` (node) и `ui` (jsdom).
- Структура папок из раздела 3.2, алиас `@/` → `src/`.
- Защита слоёв `sim ← app ← ui`: хук Claude Code, правила ESLint с тестом и `tsconfig.sim.json` без DOM.
- `GameDate` — игровой календарь как число дней, без JS `Date` (`src/sim/types/game-date.ts`).
- Дизайн-токены (Tailwind v4 `@theme static`), тёмная тема, акцент команды с автоматическим контрастным текстом, шрифты Roboto Condensed + JetBrains Mono.
- Примитивы: Button, Panel, Table, Tooltip, Dialog.
- Оболочка из 6.2: верхняя панель на моковых данных, 8 разделов, 32 вкладки-заглушки, страница «не найдено».
- i18n ru + en: типизированные ключи, русские формы множественного числа, переключатель языка.
- Демо-страница `/dev/components`.
- Скрипты `dev`, `build`, `preview`, `typecheck`, `lint`, `format`, `format:check`, `test`, `test:watch`, `sim:batch` (последний до M2 честно завершается с ошибкой).
